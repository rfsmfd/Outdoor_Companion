# Outdoor Companion

An interactive map-based companion for planning outdoor trips and scouting hunts. Track observation sites, buck profiles, and trails across your properties, and line up each spot with the wind, sun, and moon conditions that matter in the field.

## Features

- **Observation site map** — drop and manage sites on an interactive map (Leaflet + Google Maps).
- **Properties & trails** — organize sites by property and save the trails between them.
- **Buck profiles** — record and track individual buck profiles for each property.
- **Wind conditions** — wind direction and speed (mph) to help plan your approach.
- **Sun & moon times** — sunrise/sunset and moonrise/moonset for each site.
- **Weather** — current conditions pulled in for your locations.
- **Charts & export** — visualize your data (Chart.js) and export it for use elsewhere.

## Getting started

This is a self-contained web app. To run it locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/rfsmfd/Outdoor_Companion.git
   ```
2. Open `index.html` in your web browser.

No build step or server is required.
